Автор — Орлов Дмитрий Владимирович, группа М3О-410Б-23.

- [ЛР3. Управление светофорами](lr3/) — проект Quartus для DE1 и программа на C для Nios II. [Прошивка ПЛИС](lr3/output_files/DE2_115_traffic.sof) и [программа светофора](lr3/software/traffic/traffic.elf).
- [ЛР4](lr4/) — папка для следующей работы.
