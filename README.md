# САПР, лабораторная работа №2: интерфейс APB

- **Автор:** Орлов Дмитрий Владимирович
- **Группа:** М3О-410Б-23
- **Номер в списке группы:** 15

Модель ведомого устройства (slave) шины APB на SystemVerilog и тестовое окружение для ModelSim.

## Файлы (папка `apb/`)

| Файл | Назначение |
|---|---|
| `apb_master.sv` | ведущее устройство APB, задачи `apb_write` и `apb_read` |
| `apb_slave.sv` | ведомое устройство APB с регистрами 0x0, 0x4, 0x8, 0xC |
| `tb_top.sv` | модуль верхнего уровня (testbench) с автоматической проверкой |
| `run_modelsim.do` | скрипт запуска в ModelSim |

## Карта регистров

Базовый адрес устройства `0x7000_0000`.

| Смещение | Регистр | Записываемое значение |
|---|---|---|
| 0x0 | `register_with_some_name` | номер в списке группы 15 = `0x0000_000F`; при записи числа с младшим битом 0 в регистре хранится `0xAAAA_AAAA`, с битом 1 -- `0x5555_5555` |
| 0x4 | `reg_date` | дата 18.11.2026 → `0x1811_2026` |
| 0x8 | `reg_surname` | "Orlo" → `0x4F72_6C6F` |
| 0xC | `reg_name` | "Dmit" → `0x446D_6974` |

Запись или чтение по другому адресу -- ошибка, слейв выставляет `pslverr`.

## Запуск

В консоли ModelSim:

```
cd <путь к папке apb>
do run_modelsim.do
```

При успешной проверке в конце выводится `TEST PASSED`.
