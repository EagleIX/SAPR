## Запуск на плате

1. Подключите и включите DE1. В Quartus II Programmer выберите USB-Blaster и режим JTAG. Загрузите [конфигурацию ПЛИС](output_files/DE2_115_traffic.sof).
2. Откройте Nios II Command Shell в папке `lr3` и выполните `nios2-download -g software/traffic/traffic.elf`.
3. Для просмотра фаз выполните `nios2-terminal`. На HEX1 и HEX0 отображается оставшееся время фазы в секундах.

## Как процессор включает светодиоды

Процессор Nios II/e выступает мастером шины Avalon-MM. Порты PIO выступают ведомыми устройствами. В начале фазы процессор записывает битовые маски в регистры портов LEDR и LEDG. Каждый установленный бит включает соответствующий светодиод. Регистры удерживают эти значения до следующей записи.

Два светофора главной дороги показывают одинаковый сигнал. Третий управляет второстепенной дорогой. Для жёлтого сигнала у каждого светофора выделен отдельный красный светодиод.
